Setup guide

Get running in about 10 minutes

Four things to install. Each step is written for students who have never opened a terminal before.

1

Install Anki

  • 1 Go to apps.ankiweb.net and click the big download button for your operating system.
  • 2 Open the downloaded file and follow the normal install steps (like any other app).
  • 3 Launch Anki and let it finish its first-time setup.
Keep Anki open whenever you use LearnForge — it needs to be running.
2

Install AnkiConnect

  • 1 Inside Anki, go to the menu: Tools → Add-ons → Get Add-ons.
  • 2 Type in code: 2055492159 and click OK. Restart Anki when asked.
  • 3 Open the AnkiConnect config (Tools → Add-ons → AnkiConnect → Config) and add chrome-extension://* to the webCorsOriginList section.
  • 4 Restart Anki one more time.
3

Install Ollama

  • 1 Go to ollama.com and download the installer for your operating system.
  • 2 Install it like a normal app. On Mac, drag it to Applications. On Windows, run the .exe installer.
  • 3 Open a terminal (search "Terminal" on Mac/Linux, or "Command Prompt" on Windows) and run:
  • 4 ollama pull qwen2.5:7b — this downloads the AI model (about 5 GB, takes a few minutes).
  • 5 Then run OLLAMA_ORIGINS="*" ollama serve to start the AI server.
Ollama needs to keep running while you use LearnForge.
4

Load the extension

  • 1 Download the LearnForge ZIP from the releases page and unzip it.
  • 2 In Chrome or Brave, go to the address bar and type: chrome://extensions
  • 3 Toggle on Developer mode (switch in the top-right corner).
  • 4 Click Load unpacked and select the unzipped learnforge-extension folder.
  • 5 Click the puzzle-piece icon in your browser toolbar and pin LearnForge so the ⚡ icon is always visible.
